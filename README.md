Mitram AI
AI-Based Mental Wellness Monitoring and Support System

## Tech Stack
- Frontend: React + Vite
- Backend: FastAPI
- AI Integration: Gemini AI
- Deployment: Vercel + Render

## Features:
- Authentication
- AI chatbot
- Wellness assessment
- Analytics dashboard
- PDF report generation
- Personalized recommendations
